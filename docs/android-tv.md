# Установка YummyWatch на Android TV через ADB

## Подключи телевизор

Установи [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) на компьютер. Подключи компьютер и телевизор к одной домашней сети. Открой параметры разработчика на телевизоре. Обычно для этого нужно несколько раз нажать на «Номер сборки» в разделе «Об устройстве».

Если есть пункт **Беспроводная отладка** с кодом сопряжения, открой «Сопряжение устройства с помощью кода» и выполни команды ниже. Подставь адрес и порт сопряжения из окна с кодом, а для `adb connect` возьми порт подключения с основного экрана беспроводной отладки. Эти порты могут различаться.

```sh
adb pair 192.168.1.50:37099
adb connect 192.168.1.50:41555
adb devices
```

На телевизорах с **сетевой отладкой** без сопряжения включи её в параметрах разработчика и выполни `adb connect 192.168.1.50:5555`, заменив IP на адрес телевизора и указав его порт, если он отличается. Подтверди запрос отладки на телевизоре. Если сетевой отладки в меню нет, используй USB-отладку, когда модель поддерживает подключение ADB через USB. [Подключение устройства по ADB](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi)

## Выбери APK

Узнай, какие архитектуры поддерживает установленный Android. Если подключено несколько устройств, добавляй `-s IP:ПОРТ` после `adb`, используя адрес подключения из `adb devices`.

```sh
adb shell getprop ro.product.cpu.abilist
```

Выбери APK в [GitHub Releases](https://github.com/vicimpa/yummywatch/releases/latest) по первому подходящему ABI из списка телевизора. Даже на 64-битном процессоре телевизор может использовать 32-битный Android и показывать только `armeabi-v7a`.

| ABI в выводе ADB | Суффикс файла                |
| ---------------- | ---------------------------- |
| `arm64-v8a`      | `-AndroidTV-arm64-v8a.apk`   |
| `armeabi-v7a`    | `-AndroidTV-armeabi-v7a.apk` |
| `x86_64`         | `-AndroidTV-x86_64.apk`      |
| `x86`            | `-AndroidTV-x86.apk`         |

## Установи и запусти

Подставь имя скачанного APK. Ключ `-r` обновляет установленный YummyWatch с той же подписью и сохраняет данные приложения.

```sh
adb install -r YummyWatch-0.0.11-AndroidTV-arm64-v8a.apk
```

После сообщения `Success` открой YummyWatch в списке приложений на телевизоре. Если ADB сообщает `INSTALL_FAILED_NO_MATCHING_ABIS`, проверь архитектуру. Если появляется `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, установленная сборка подписана другим ключом. Это возможно после тестового APK. Удаление старого приложения стирает его локальные данные, поэтому сначала сохрани нужные данные. После установки отключи отладку на телевизоре. [Команды установки ADB](https://developer.android.com/tools/adb#move)
