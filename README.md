YummyWatch — приложение для просмотра аниме из каталога YummyAnime. Находи новые тайтлы, выбирай озвучку и продолжай смотреть с того места, где остановился. На компьютере интерфейсом можно управлять мышью и клавиатурой. Мобильная раскладка рассчитана на касания.

## Скачать

Готовые установщики находятся в [GitHub Releases](https://github.com/vicimpa/yummywatch/releases/latest). Токен приложения уже включён: свой API-ключ для обычного использования не нужен. Node.js и Rust для установки не нужны.

| Платформа  | Архитектура               | Пакеты                              |
| ---------- | ------------------------- | ----------------------------------- |
| macOS 12+  | Apple Silicon (ARM64)     | отдельный `.dmg`                    |
| macOS 12+  | Intel (x86_64)            | отдельный `.dmg`                    |
| Windows    | x64                       | `.exe` (NSIS), `.msi`               |
| Linux      | x86_64                    | `.deb`, `.rpm`, `.AppImage`         |
| Arch Linux | x86_64                    | `.pkg.tar.zst` для pacman           |
| Android TV | ARM64, ARMv7, x86_64, x86 | [APK через ADB](docs/android-tv.md) |

Windows и Linux воспроизводят видео через libmpv. Windows-установщики включают DLL. Linux-бинарник собирается на Ubuntu 24.04. AppImage включает libmpv, а DEB, RPM и Arch используют библиотеку дистрибутива. Пакет Arch собирается через `makepkg` и проверяется установкой в актуальном Arch Linux.

Для Arch скачай пакет `linux-x64-…pkg.tar.zst` со страницы релиза. Выполни `sudo pacman -U` с путём к скачанному файлу.

Для Nix и NixOS на x86_64 и ARM64 Linux доступен flake. Он собирает приложение из исходников и включает libmpv, WebKitGTK и медиаплагины GStreamer:

```sh
nix run github:vicimpa/yummywatch

# Или из локальной копии репозитория:
nix build
./result/bin/yummywatch
```

Пакеты macOS и Windows поставляются без сертификатов Apple Developer ID и Windows Authenticode. Контрольные суммы установщиков находятся в `SHA256SUMS.txt`.

В GitHub Releases доступны установщики для компьютера. Сборки для Android и iOS пока доступны из исходников.

### Серое окно при запуске на Linux

Если на Wayland с NVIDIA открывается пустое серое окно, полностью закрой приложение и попробуй запустить его с передачей кадров через общую память.

```sh
env -u WEBKIT_DISABLE_DMABUF_RENDERER WEBKIT_DMABUF_RENDERER_FORCE_SHM=1 yummywatch
```

Если окно всё ещё серое, попробуй запуск через XWayland с отключённым DMA-BUF-рендерером.

```sh
env -u WEBKIT_DMABUF_RENDERER_FORCE_SHM GDK_BACKEND=x11 WEBKIT_DISABLE_DMABUF_RENDERER=1 yummywatch
```

Для AppImage подставь путь к файлу вместо `yummywatch`.

## Возможности

- **Каталог и поиск.** Подборки, фильтры по жанрам, году и рейтингу, расписание премьер. Следующие страницы подгружаются при прокрутке; виртуальная сетка сохраняет отзывчивость больших списков.
- **Страница аниме.** Описание, факты, кадры, озвучки и порядок просмотра с выделением открытого тайтла. Распределение зрительских оценок от 1 до 10, средняя оценка и число голосов. Личную оценку можно поставить, изменить или снять; в профиле доступен личный топ по своим оценкам. Оценки аккаунта сохраняются в YummyAnime, гостевые — на устройстве.
- **Единый плеер.** Выбор серии, озвучки, качества, скорости и источника потока. В режиме «Авто» плеер пробует другой источник той же серии и озвучки, если поток недоступен. Во время воспроизведения приложение удерживает экран включённым.
- **Плеер на macOS.** «Наш плеер» воспроизводит видео через libmpv и сохраняет позицию при смене качества. Режим «Картинка в картинке при выходе из плеера» позволяет продолжить просмотр при переходе в каталог. Апскейл и резкость контуров настраиваются в плеере.
- **Продолжение просмотра.** Позиция сохраняется локально и синхронизируется с аккаунтом YummyAnime. Гостевая коллекция хранится отдельно от аккаунта.
- **Профили.** Личный обзор, коллекция, избранное, полная история просмотра и подписки на озвучки в одном профиле; поиск, сортировка и фильтры внутри списков. Статистика YummyAnime: календарь за 180 дней, время по форматам, жанры и личные оценки. Друзья, поиск людей и переходы в профили из комментариев. Описание и приватность списков редактируются с сохранением в аккаунт; гостевой профиль работает без входа.
- **Новые версии.** Приложение проверяет стабильные релизы GitHub через секунду после запуска и затем раз в пять минут. Неизменившийся ответ запрашивается через ETag, ограничения частоты GitHub учитываются. Уведомление об обновлении открывается из навигации и ведёт к описанию версии и установщикам.
- **На связи.** Уведомления и личные сообщения YummyAnime приходят через общее соединение с автоматическим восстановлением. В приложении можно отвечать друзьям, читать уведомления и подписываться на новые серии выбранной озвучки и источника. Статусы друзей обновляются без перезагрузки. Системные уведомления для свёрнутого приложения включаются отдельно в настройках.
- **Диалоги и возврат.** Переписка открывается как отдельный мессенджер со списком собеседников и закреплённым вводом. Кнопки «Назад» и «Вперёд» возвращают к исходной вкладке профиля и позиции страницы. Профили, списки и статистика сохраняются в кэше и обновляются в фоне.
- **Обсуждения.** Ответы раскрываются деревом под комментариями. Новые комментарии и ответы пишутся в одной нижней форме, как в чате: Enter отправляет, Shift+Enter добавляет строку. Адресата можно сменить без потери текста; доступны спойлеры и сохранение черновика.
- **Опенинги и следующая серия.** Ручной пропуск, автопропуск по меткам источника и автопереход. Автоматические действия предваряет отсчёт с возможностью отмены.
- **Масштаб в Linux.** По умолчанию учитываются масштаб экрана GTK и системный DPI текста. В настройках интерфейса можно выбрать масштаб от 75% до 200% или вернуться к значению «По системе».
- **Клавиатура и касания.** Боковая навигация на компьютере, нижняя — на телефоне. Панели серий и комментариев открываются поверх видео. Масштабирование, поворот и безопасные отступы учтены в мобильной раскладке.
- **Кэш страниц и изображений.** Уже открытые описания, постеры и расписание доступны без сети и обновляются в фоне. Для видеопотоков и синхронизации коллекции нужен интернет.

Поддерживаются источники Kodik, Aksor, CVH и Alloha. Доступность конкретной серии и озвучки зависит от источника.

Discord Rich Presence включён по умолчанию; его можно отключить в настройках десктопного приложения. В профиле появляются название аниме, серия, постер, статус воспроизведения и нативная полоса прогресса с просмотренным и оставшимся временем. Кнопки ведут на страницу аниме и загрузку YummyWatch. Вне просмотра показываются текущий раздел, выбор аниме и поисковый запрос. Под ником отображается название аниме или запрос. Нужен запущенный Discord с разрешённым отображением активности. Во время загрузки потока уже отображаются аниме, серия и статус «Загрузка», без таймера. На паузе таймер убирается, после пяти минут карточка скрывается.

## Управление

| Действие                       | Клавиши                 |
| ------------------------------ | ----------------------- |
| Выбрать элемент / открыть      | Стрелки или Tab / Enter |
| Назад / закрыть панель         | Esc, Backspace          |
| Поиск                          | `/`, Ctrl/⌘ K           |
| Пауза                          | Пробел, K               |
| Перемотка на 10 секунд         | J / L                   |
| Звук / полный экран            | M / F                   |
| Серии / комментарии / об аниме | E / C / I               |

Сочетания не мешают вводу текста. Esc закрывает открытую панель или меню. Если они закрыты, клавиша выводит из полноэкранного режима или возвращает назад. На компьютере полноэкранный режим сохраняется при переходе между просмотром и каталогом. Управление плеера скрывается во время просмотра и появляется при движении мыши или касании.

## Разработка

Нужны Node.js 22.12+, стабильный Rust (не ниже 1.90) и [системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/).

Для десктопной сборки на macOS нужны Xcode Command Line Tools, `pkg-config` и Python 3 с пакетами `meson`, `ninja` и `Jinja2`. Для iOS нужен полный Xcode.

```sh
npm ci
cp .env.example .env.local
# Укажи в .env.local публичный VITE_YUMMY_APPLICATION_TOKEN.
npm run dev
```

Публичный токен приложения выдаётся в [настройках приложений YummyAnime](https://yummyani.me/dev/applications). Он включается в клиентскую сборку. Пароль и токен пользовательского аккаунта в `.env.local` не добавляются.

```sh
npm run build          # установщики для текущей ОС
npm test               # логика и UI
npm run test:rust      # Rust-бэкенд и внутренний медиа-протокол
npm run check:mobile   # мобильная геометрия и автоподгрузка в Chromium/WebKit
npm run check:layout   # desktop, прокрутка, окна и полный экран
npm run screenshots   # обновить настоящие снимки desktop/mobile
npm run icons         # пересоздать иконки из public/icons/icon.svg
```

Для браузерных проверок нужны установленный Google Chrome и Playwright WebKit (`npx playwright install webkit`). Для CI/Chromium — `npx playwright install chromium webkit`. Снимкам и проверкам живых источников нужен доступ к YummyAnime и источникам видео.

`npm run dev:web` запускает веб-стенд интерфейса. Полный набор нативных источников проверяй через `npm run dev`.

### Мобильная разработка

```sh
npm run init:android
npm run dev:android

npm run init:ios
npm run dev:ios
```

Android требует JDK, SDK/NDK и Rust targets. iOS — macOS, Xcode, CocoaPods и Apple development team. Сгенерированные проекты создаются закреплённой в lockfile версией Tauri CLI и не хранятся в Git. Подробности — в [инструкции по сборке и релизам](docs/releases.md).

На Android TV включается облегчённый режим с управлением пультом и отключёнными анимациями. `npm run build:android:tv` собирает отдельные APK для `arm64-v8a`, `armeabi-v7a`, `x86_64` и `x86`. Чтобы собрать один APK, передай ABI, например `npm run build:android:tv -- armeabi-v7a`. Для подписи используй переменные из [инструкции по релизам](docs/releases.md). [Установка на телевизор через ADB](docs/android-tv.md)

Android воспроизводит видео через libmpv на нативной поверхности с аппаратным декодированием MediaCodec. Сборка проверяет SHA-256 скачанных APK, из которых берёт libmpv и FFmpeg. [mpv-android 2025-08-25](https://github.com/mpv-android/mpv-android/releases/tag/2025-08-25)
